# Café Andino – Sitio web

Proyecto de sitio web

## Tarea a realizar
1. El proyecto contiene las carpetas js, css, images y test.
2. Incluye los archivos README.md y .gitignore.
3. Este README.md describe la tarea a realizar.
4. El .gitignore omite todo el contenido de la carpeta test.
5. Sitio web de tema libre (café peruano). El CSS se escribió con apoyo de IA.
6. Se usa HTML semántico (<header>, <nav>, <main>, <section>, <footer>) e incluye imágenes, tablas, enlaces, formularios y un footer con contacto y redes sociales.
7. Todo el contenido está en index.html. Los estilos están en css/estilos.css y las funciones en js/funciones.js.

## Estructura
cafe-andino/
├── index.html
├── README.md
